# BeReal Morphe Patches

Morphe patch source for BeReal (`com.bereal.ft`), currently targeting version `3.97.1`.

## Morphe Manager source

Add this repository URL as a patch source:

`https://github.com/mwbra130/Private`

The source metadata is published in [`patches-bundle.json`](patches-bundle.json). The downloadable `.mpp` release asset is generated by GitHub Actions.

## Build

The GitHub Actions workflow builds the Morphe patch bundle and updates `patches-list.json` and `patches-bundle.json` on pushes to `main`.

Compatibility is version-specific. Check the patch list and release notes before using a bundle with another BeReal version.
